IIDX 練習カウンター（ブラウザ / PWA）
===================================

【機能】
・曲名ごとに独立したカウント、＋1/−1
・目標回数と達成率を表示
・日付、スコア、メモを編集
・当日の練習回数、累計、曲数の表示
・検索、コンパクト / 複数列 / 1列の切り替え
・自動保存、JSONバックアップと復元

【すぐ使う（簡易版）】
単独の「IIDX練習カウンター.html」をスマホ/PCのブラウザで開きます。
※ file:// 形式のHTMLを直接開いた場合、ブラウザによっては
   ローカル保存が制限されたり、データが消えたりする場合があります。
   安定運用には下記のHTTPS公開を推奨します。

【Androidのホーム画面に追加する方法】
1. ZIPを展開し、フォルダ内のファイルをGitHub Pagesなどの
   HTTPSで公開できる静的サイトに置きます。
2. AndroidのChromeから公開URLへアクセスします。
3. ブラウザのメニューから「ホーム画面に追加」または「アプリをインストール」。
4. オフラインでも使用可能です（初回読み込みが完了している場合）。

【データについて】
記録は使用中のブラウザの localStorage に保存されます。
別の端末・ブラウザには自動同期されません。
機種変更やブラウザデータ削除の前に、画面右上の歯車から
JSONのバックアップをダウンロードしてください。
